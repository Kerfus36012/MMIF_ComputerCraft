# MMIF (multi media image format)
### MMIF video supports DFPWM AUDIO!!! 

This format was created as a experiment and replacement for the built-in NFP image format.

### files:
- mmif_viewer					      : can display image and video (only for CraftOS-PC ENV)
- MMIFv2_viewer             : copy of mmif_viewer but works in minecraft YEY!!! 
- mmif_conv				          : python script for converting other formats into MMIF

(MMIF-video may crashing the CC)
for using in ComputerCraft/tweaked: check for https://github.com/sashafiesta/CC-Graphics
